# Mohammed Rizwan — A Life in Motion

A Next.js + TypeScript founder portfolio with GSAP ScrollTrigger, Lenis, and a dynamically loaded React Three Fiber scene.

## Run

- `npm install`
- `npm run dev`
- `npm run build` (static export in `out/`)
- `npm run typecheck`

## Creative concept

Movement is the unifying idea: an international personal journey becomes a connected automotive ecosystem, then a global mobility ambition. The experience uses an ivory editorial palette, forest-green typography, a restrained copper accent, portrait-led compositions, and distinct interactions tied to the story.

The single continuous narrative preserves momentum without requiring visitors to navigate multiple introductory pages. Progressive disclosure in the business ecosystem and leadership section keeps detail available without overwhelming each scene.

## Interaction and accessibility

- Desktop-only pinned three-country journey; normal vertical flow on mobile and when reduced motion is requested.
- Keyboard-operable business selectors, previous/next controls and leadership disclosures.
- Mobile menu closes on Escape and selection.
- Focus indicators, skip link, semantic landmarks, image alternatives, live business detail announcements.
- Reduced-motion preference disables scroll choreography and continuous 3D rendering.
- Globe renders only near the viewport; DPR capped at 1.5, dynamic bundle, WebGL failure fallback.
- Globe routes illustrate the founder's journey, not live rental availability.
